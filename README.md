# Waypoint WiPay for Shopify

An independent Shopify integration research project maintained by Waypoint. It is not affiliated with, sponsored by, or endorsed by WiPay.

## Project status

**Partner feasibility only.** No Waypoint-supported Shopify payment gateway is available. Shopify requires payment gateway apps to use its Payments API and obtain authorization. WiPay's published page points to a third-party bridge; it is not a Waypoint product.

See [PLATFORM-RESEARCH.md](PLATFORM-RESEARCH.md) for the authorization gate, third-party bridge questions, and official references.
